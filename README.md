
# Python OOP Bank Management System

## About
A simple menu-driven Bank Management System built using Python and Object-Oriented Programming (OOP).

## Features
- Deposit money
- Withdraw money
- Check account balance
- Display account details
- Input validation
- Menu-driven interface

## OOP Concepts Used
- Classes and Objects
- Constructors
- Encapsulation
- Instance Methods
- Class Variables

## Technologies
- Python 3

## How to Run

```bash
python3 bank_management.py
```

## Purpose
This project was developed to practice Python OOP concepts through a simple banking application.
